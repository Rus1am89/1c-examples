# Загрузка файлов на Диск Битрикс24

Внешняя обработка 1С: выбранный файл загружается на общий диск компании в Битрикс24 через REST API (входящий вебхук).

- Платформа 8.3.x, управляемые формы, работает в тонком и веб-клиенте.
- Не зависит от конфигурации: подключается в любую базу через «Дополнительные отчёты и обработки» или открывается через «Файл → Открыть».
- Модуль объекта можно вызывать из своего кода: `ЗагрузитьФайлНаДискБитрикс24(ПутьКФайлу, ИмяФайла, АдресПортала, КодВебхука)` возвращает структуру `Успех, Сообщение, Результат`.

## Как устроено

1. **Клиент.** Файл выбирается через `НачатьПомещениеФайла` и кладётся во временное хранилище, поэтому работает и в веб-клиенте, где нет доступа к локальной файловой системе.
2. **Сервер.** Через `disk.storage.getlist` определяется корневая папка общего диска (`ENTITY_TYPE = common`). Если общего диска нет, берётся первое доступное хранилище.
3. **Загрузка.** Вызывается `disk.folder.uploadfile`, содержимое передаётся в Base64 **в теле POST** (`application/x-www-form-urlencoded`), а не в строке запроса. Так обходится ошибка `414 Request-URI Too Large` на файлах крупнее нескольких килобайт.
4. **Повтор имени.** При совпадении имени Битрикс24 сам создаёт уникальное (`generateUniqueName=Y`).
5. **Диагностика.** Ошибки — HTTP-код, ответ Битрикс24, размеры файла и тела запроса — пишутся в лог на форме. По логу видно, что именно не так: адрес, права вебхука или размер файла.

## Настройка

В Битрикс24: «Разработчикам → Другое → Входящий вебхук», права — **disk**. В обработке указать:

- адрес портала — `mycompany.bitrix24.ru` (схема и путь отрежутся сами);
- код вебхука — `/rest/1/xxxxxxxxxxxxxxxx/`.

## Ограничения

- Файл передаётся одним запросом. Облачный Битрикс24 принимает тело до ~35 МБ, то есть файлы примерно до 20 МБ.
- Загрузка в корень общего диска. Выбор папки — очевидное расширение через `disk.folder.getchildren`.

## Состав

- `ЗагрузкаФайловНаДискБитрикс24.epf` — готовая обработка.
- `src/` — исходники, выгрузка Конфигуратора в файлы (иерархический формат):
  - `Ext/ObjectModule.bsl` — модуль объекта: работа с REST API;
  - `Forms/Форма/Ext/Form/Module.bsl` — модуль формы: выбор файла, клиент-серверный вызов, лог.
